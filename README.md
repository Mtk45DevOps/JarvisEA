# SythnVPS-Jarvis EA

An automated Fibonacci-based trading bot for MetaTrader 5.

## Features

- Fibonacci 70.5% retracement entries
- Automatic lot sizing
- Money-based Take Profit & Stop Loss
- Multiple trade management
- AWS API integration
- Remote control (in development)

## Language

- MQL5

## Platform

- MetaTrader 5
